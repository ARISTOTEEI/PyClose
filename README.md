# PyClose

Discord-бот для проведения Dota 2 клозов в формате 5 на 5.

Бот создает отдельную категорию Discord-каналов для каждого клоза, собирает игроков, распределяет их по позициям и помогает запустить или отменить игру. Поддерживаются два режима записи:

- **По командам** — игрок выбирает сторону: силы света или силы тьмы, а затем позицию.
- **Случайный** — игрок выбирает одну из пяти позиций, а состав формируется без выбора стороны.

## Возможности

- создание и отмена клоза через Discord-интерфейс;
- запись игроков на позиции с кнопок;
- уведомление записавшихся и приглашение игроков на свободные позиции;
- удаление игрока из записи;
- запуск клоза после набора состава;
- автоматическое создание текстовых и голосового каналов для клоза;
- хранение клозов, пользователей и записей в PostgreSQL;
- управление активными клозами владельцем приложения.

## Требования

- Python 3.13 или новее;
- PostgreSQL;
- Discord-приложение с ботом и токеном;
- права бота на сервере для чтения событий, управления каналами и участниками голосовых каналов.

## Установка

Клонируйте репозиторий и установите зависимости. Для `uv`:

```bash
uv sync
```

Или установите проект через `pip`:

```bash
python -m pip install -e .
```

Создайте файл `app/.env`:

```env
TOKEN=your_discord_bot_token

DB_USER=postgres
DB_PASS=your_database_password
DB_NAME=closebot
DB_HOST=127.0.0.1
DB_PORT=5432
```

`TOKEN` — токен Discord-бота. Остальные переменные используются для подключения к PostgreSQL через `asyncpg`.

## Подготовка базы данных

После создания базы примените миграции:

```bash
uv run alembic upgrade head
```

Для запуска через `pip` используйте:

```bash
alembic upgrade head
```

## Запуск

Из корня проекта выполните:

```bash
uv run python main.py
```

Или:

```bash
python main.py
```

При успешном подключении бот выведет в консоль сообщение о том, что он находится в сети.

## Команды

### `/close`

Создает новый клоз. Команда доступна участникам с ролью клозмейкера и принимает режим:

- `Рандом`;
- `По командам`.

После создания бот добавляет категорию с каналами управления, записи и ожидания. Управление клозом доступно создателю через кнопки в канале управления.

### `/ping`

Показывает текущую задержку бота.

### `/closemanager`

Техническая команда владельца приложения для просмотра и удаления активных клозов.

## Настройка Discord

Идентификаторы ролей, каналов и эмодзи задаются в `app/config.py`. Перед запуском проверьте, что:

1. роли из конфигурации существуют на сервере;
2. у бота есть права создавать и удалять категории и каналы;
3. у бота есть права перемещать, отключать звук и исключать участников из голосовых каналов;
4. бот добавлен на сервер с необходимыми intents.

## Структура проекта

```text
main.py                 Точка входа
app/client.py            Инициализация Discord-бота
app/config.py            Настройки окружения и Discord
app/commands/            Slash-команды
app/buttons/             Обработчики кнопок клоза
app/menu/                Меню управления клозом
app/events/              Обработчики событий и ошибок
app/utils/models.py      SQLAlchemy-модели
app/utils/database.py    Подключение к PostgreSQL
migration/               Миграции Alembic
```

## Разработка

Создание новой миграции после изменения моделей:

```bash
uv run alembic revision --autogenerate -m "описание изменения"
uv run alembic upgrade head
```

Не добавляйте файл `app/.env` в репозиторий: он содержит токен бота и пароль базы данных.
